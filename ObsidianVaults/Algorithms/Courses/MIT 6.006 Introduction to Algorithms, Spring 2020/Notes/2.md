# Interface (API / ADT) vs Data Structure (DS)

**Interface** is a **specification**: what operations are supported (the **problem**!)
**Data structure** is a **representation**: how operations are supported (the **solution**!)

# Sequence interfaces

| Interface Name | Operation                                                                                               |
| -------------- | ------------------------------------------------------------------------------------------------------- |
| Container      | build(X)<br>len()                                                                                       |
| Static         | iter_seq()<br>get_at(i)<br>set_at(i, x)                                                                 |
| Dynamic        | insert_at(i, x)<br>delete_at(i)<br>insert_first(x)<br>delete_first()<br>insert_last(x)<br>delete_last() |
